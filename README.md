# My EV Battery

App web gratuita para donos de carros elétricos que carregam em casa: % estimado da bateria durante o carregamento, custo em € (tarifa simples ou bi-horária) e consumo do carro entre carregamentos.

- Funciona no browser do telemóvel (iPhone e Android) e pode ser adicionada ao ecrã principal.
- Os dados ficam guardados apenas no telemóvel de cada pessoa.
- Bateria útil dos modelos: EV Database (ev-database.org), novembro de 2026.

Site: https://bn55kyfr22-cyber.github.io/my-ev-battery/
